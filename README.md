# Abbey Wood Community Group Website

A modern, high-converting single-page website for Abbey Wood Community Group — a community centre and hall-hire venue in Abbey Wood, London.

## Overview

This project is a standalone HTML landing page designed to convert visitors into customers by showcasing the venue's services, real customer testimonials, and clear call-to-action buttons.

## Features

- **Hero Section** — Bold headline with venue stats, floating rating cards, and dual CTAs (Call / Explore)
- **Services** — Six cards highlighting hall hire, laminating, photocopying, community groups, and parking
- **About** — Feature list and review badge building trust
- **Testimonials** — Six real Google review quotes with a link to all 81 reviews
- **FAQ** — Answers to common questions about pricing, parking, facilities, deposits, transport, and hours
- **Call to Action** — Prominent booking CTA block
- **Footer** — Contact details, directions, social links, and newsletter signup
- **Fully Responsive** — Hamburger menu, flexible grids, and mobile-optimized spacing
- **Accessibility** — Semantic HTML, ARIA labels, skip-link, prefers-reduced-motion support
- **SEO** — Schema.org LocalBusiness structured data, Open Graph tags, meta descriptions, canonical URL

## Tech Stack

- HTML5 (single self-contained file)
- CSS3 (embedded styles with CSS custom properties)
- Vanilla JavaScript (smooth scroll, mobile nav, reveal animations)

## Getting Started

1. Clone the repository
2. Open `freetest.html` in any modern web browser

No build step or server required.
